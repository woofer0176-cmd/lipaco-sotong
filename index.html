공지 쓰기

📱 휴대폰에 앱처럼 설치하기

① 카카오톡에서 링크를 받았다면 먼저 브라우저로 열기

  1. 카톡에서 링크를 누르면 카톡 안에서 열립니다
  2. 오른쪽 위 ⋮를 누릅니다
  3. 다른 브라우저로 열기를 누르고 크롬이나 삼성 인터넷을 고릅니다

② 안드로이드 · 크롬

  1. 오른쪽 위 ⋮를 누릅니다
  2. 홈 화면에 추가를 누릅니다
  3. 설치 또는 추가를 누르면 바탕화면에 아이콘이 생깁니다

② 안드로이드 · 삼성 인터넷 (갤럭시 기본 브라우저)

  1. 아래쪽 ≡ 메뉴를 누릅니다
  2. 현재 페이지 추가를 누릅니다
  3. 홈 화면을 고르고 추가를 누릅니다

② 아이폰 · 사파리

  1. 카톡에서는 오른쪽 아래 ⋯ → Safari로 열기를 누릅니다
  2. 아래쪽 공유 버튼 ⬆︎를 누릅니다
  3. 홈 화면에 추가 → 추가를 누릅니다

한 번 설치하면 다음부터는 바탕화면 아이콘만 누르면 됩니다. 로그인도 기억됩니다.

✏️ 요청 보내기

  1. 요청 탭에서 분류를 고릅니다
    새 기능 · 개선 · 오류 신고 · 기타
  2. 제목은 한 줄로 짧게 씁니다
    예: 출퇴근 기록을 앱에서 하고 싶어요
  3. 내용에는 언제, 어떤 상황에서, 무엇이 필요한지 적습니다
  4. 화면을 보여 주면 이해가 빠릅니다. ＋를 눌러 사진이나 캡처를 최대 3장 붙이세요
    PC에서는 사진을 끌어다 놓거나 Cmd+V(Ctrl+V)로 붙여 넣어도 됩니다
  5. 요청 보내기를 누르면 끝입니다
